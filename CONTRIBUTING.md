# Contributing

Contributions are welcome after the public repository opens.

1. Discuss user-visible changes in an issue first.
2. Keep Simple Mode understandable without technical knowledge.
3. Put technical controls in Advanced Mode.
4. Never add automatic deletion or file-content scanning.
5. Add or update tests for behavioural changes.
6. Keep all code comments in English.
7. Preserve Swedish, English, Danish, and Norwegian Bokmål localisation coverage.

By contributing, you agree that your contribution is licensed under the MIT License.
